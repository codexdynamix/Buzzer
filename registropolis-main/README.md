# Buzzer frontend

This directory contains the Buzzer Vite/React application. Run it through the repository root, which starts the Express API and Vite development server together:

```sh
npm run dev
```

Supabase Auth and Postgres configuration, schema setup, and deployment notes are in the [repository README](../README.md). The former standalone API in this directory has been removed; the supported backend is the root `server.ts`.
